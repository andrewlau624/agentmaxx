# Tells in code, commits, PRs and security reports: sources

Scope: signs that source code, commit messages, pull request descriptions or security reports were written by an AI model, collected for a deterministic linter. Every row in the catalog cites a page fetched on 2026-10-03, and every quote was copied from the text of that page. Whitespace was normalised when the HTML was converted to text; the words were not changed. Claims that could not be tied to a fetched page and a quote are listed under "Not verified" and are left out of the catalog.

Read the directions with care. Several studies compare agents with each other, not with humans. Others report only how often a rule fires in AI code, with no human baseline. The catalog says which kind of finding each row is. The linter READMEs are tool authors' assertions, not measurements.

## Not verified

These items were left out of the catalog because no page was fetched or no supporting quote was found:

- GPTSniffer and DetectGPT4Code: neither paper was fetched, so they contribute no features.
- "Is This You, LLM? Recognizing AI-written Programs with Multilingual Code Stylometry" (arXiv 2412.14611), and "Distinguishing LLM-generated from Human-written Code by Contrastive Learning" (arXiv 2411.04704, CodeGPTSensor): both appeared in search results only, and neither was fetched.
- The claim that Stenberg described slop reports as having a "confident tone, overly polite language" and as citing functions that do not exist. This came from a search-engine summary of a Cybernews article, which was not fetched. The fetched curl pages support "fabricated details" and hallucinations (S14, S11), not that wording.
- "AI-generated code had 63% more code smells" (attributed to Paul et al. 2025), and "30% more static analysis warnings and 41% more code complexity" (attributed to He et al. 2025): both are secondhand claims from search summaries.
- The aislop / scanaislop rule names (trivial-comment, narrative-comment, meta-comment); the DEV article "The 22 patterns of AI code slop"; the AI-SLOP-Detector rule list: these were seen only in search summaries.
- A Claude Code PR template with "## Summary" and "## Test plan" headings: no fetched source documents it.
- The discussion thread on HackerOne report 2298307: the JSON endpoint returned the report body but no activity messages.
- Studies that measure the length or structure of AI-written commit-message bodies, as opposed to trailers: no source was found. Every commit-level source here identifies agents by trailers or metadata.
- QEMU and NetBSD policies: fetched, but they contain no observable signs. They are provenance bans.
